# Ryujinx Nintendo Switch Emulator

**Ryujinx Nintendo Switch Emulator** v1.1.1509 (September 8, 2026) is a canary desktop build. ryujinx emulator, nintendo switch emulator, ryujinx mods, yuzu emulator. 4K 60FPS, Vulkan, LDN, LayeredFS. Firmware and keys come from your own console dump.

## Setup
1. Firmware - Tools > Install Firmware (18.x / 19.x from your dump).
2. Keys - prod.keys in the system folder.
3. Games - add a folder of NSP/XCI files.
4. Notes in `files/notes/`.

## FAQ

**Vs Yuzu?**
Yuzu stopped in 2024. This stays the accuracy-first desktop option. Eden covers phones.

**Android / apk?**
No official Android build.

**Dump?**
Firmware, keys and games from a console you own.

## Requirements
Windows 10/11 x64. Vulkan 1.1+. 8 GB RAM (16 GB better). SSD for shaders.
